# MRKT Free Giveaway Auto-Joiner

Юзербот, який сам бере участь у **безплатних** розіграшах MRKT (@mrkt), де умова — тільки підписка на один або кілька каналів.

## Що робить
1. Логіниться в MRKT від твого Telegram-акаунта (як відкриття міні-аппа).
2. Кожні 2 хв бере список активних розіграшів з вкладки **Free**.
3. Пропускає розіграші з платними квитками, бустом каналу, умовою «Premium» або «active trader», а також ті, де каналів більше ніж `max_channels`.
4. Підписується на канали з паузою 15–35 с, щоб не ловити FloodWait. Далі тисне в MRKT «перевірити», чекає на підтвердження і натискає **Participate**.
5. Коли розіграш закінчився (+1 год), відписується від каналів, на які підписався **сам бот**. Ті, де ти був раніше, не чіпає. Вимикається через `"leave_after_end": false`.

## Встановлення
```powershell
pip install -r requirements.txt
```
1. Зайди на https://my.telegram.org → API development tools → створи app → візьми `api_id` і `api_hash`.
2. Скопіюй `config.example.json` у `config.json` і впиши туди `api_id` і `api_hash`.

## Запуск
Спершу перевір, що бот бачить розіграші (нічого не підписує):
```powershell
python bot.py --dry
```
Першого разу Telethon попросить номер телефону і код з Telegram (вводиш сам у консолі). Після цього з'явиться файл `mrkt_session.session`, і код більше питати не буде.

Робочий режим:
```powershell
python bot.py
```
або двічі клацни `start.bat`. Додай `-v`, щоб у лозі було видно, чому кожен розіграш пропущено.

## Бот-пульт (@pasivch1kbot)
Токен уже в `config.json` (`bot_token`). Бот **не бере участь** у розіграшах (MRKT пускає тільки реальні акаунти), він тільки показує, що відбувається, і приймає команди.
1. Відкрий @pasivch1kbot і натисни **Start** (інакше він не зможе тобі писати).
2. Запусти `python bot.py`, і бот напише «MRKT бот запущено».

Сповіщення: участь у розіграші, **виграш** 🏆, помилки, ліміт каналів, зупинка.
Команди (відповідає тільки власнику, тобто акаунту, з якого залогінений юзербот):
`/status` `/list` `/run` (перевірити зараз) `/pause` `/resume`

## Хостинг 24/7 (Render + UptimeRobot, безплатно)
1. `python export_session.py` створює `.env.render` з усіма секретами (сесія = повний доступ до акаунта, нікому не давай).
2. https://render.com: входиш через GitHub, далі **New → Blueprint**, обираєш репо `mrkt-giveaway-bot` (Render сам прочитає `render.yaml`).
   Якщо Blueprint не підходить, тисни **New → Web Service**, Build `pip install -r requirements.txt`, Start `python bot.py`, план Free.
3. Відкриваєш Environment → **Add from .env** і вставляєш вміст `.env.render`.
4. **Локальний бот має бути вимкнений**, бо одна сесія у двох місцях = ризик, що Telegram її скине.
5. https://uptimerobot.com: Add monitor → HTTP(s) → `https://<твій-сервіс>.onrender.com/` → кожні 5 хв (інакше Render присипляє сервіс через 15 хв).

Стан (`state.json`) на сервері зберігається в «Збраному» твого Telegram-акаунта (файл `#mrkt_state`). Не видаляй його.

## Файли
- `state.json` — у яких розіграшах уже бере участь і від чого треба відписатись
- `bot.log` — лог
- `*.session` — **твоя сесія Telegram, нікому не давай**

## Налаштування (`config.json`)
| ключ | що це |
|---|---|
| `max_channels` | макс. кількість каналів у розіграші |
| `check_interval_sec` | пауза між перевірками |
| `join_delay_sec` | пауза між підписками [від, до] |
| `leave_after_end` | відписуватись після кінця розіграшу |
| `allow_premium_only` | брати розіграші «тільки Premium» (якщо в тебе є Premium) |
| `skip_channels` | канали, на які не підписуватись |
| `proxy` | проксі для запитів до MRKT |

## Ризики
Автоматизація може порушувати правила MRKT, і акаунт можуть обмежити в розіграшах. Масові підписки можуть дати FloodWait від Telegram. Бот це обробляє, але паузи краще не зменшувати. У Telegram ліміт ~500 каналів, тому `leave_after_end` краще не вимикати.
